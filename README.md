# FileNamePathChecker
This program identifies files with the same name in a folder based on customizable patterns, allowing certain parts of filenames (like specific suffixes or strings) to be ignored.

Through this program, files with the same name can be found in a folder based on specific patterns. For example, if two files are named Test.txt and Test.doc, they are considered files with the same name. Or for instance, if we have Test-Path.txt and Test.doc, we can configure the program to ignore “-Path”; in that case, these two files will also be considered as having the same name.
